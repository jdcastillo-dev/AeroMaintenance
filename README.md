
# AeroMaintenance 

## Descripción
AeroMaintenance es un sistema de gestión de mantenimiento aeronáutico desarrollado en Java, aplicando los principios de programación orientada a objetos (POO).

El sistema permite administrar aeronaves, técnicos, órdenes de mantenimiento, inspecciones y hangares mediante una interfaz de consola.

## Funcionalidades
- Registrar y consultar aeronaves.
- Registrar y consultar técnicos de mantenimiento.
- Crear y consultar órdenes de mantenimiento.
- Registrar inspecciones asociadas a órdenes de mantenimiento.
- Registrar hangares y asignar aeronaves.
- Generar reportes de aeronaves y órdenes de mantenimiento.
- Validar datos y evitar registros duplicados.

## Ejecución
1. Clonar o descargar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Configurar un JDK compatible.
4. Ejecutar la clase `Main.java`.
5. Utilizar el menú de consola para acceder a las funcionalidades.
